# E-Commerce Sales Analysis 📊

## About the Project

I built this project to practise my data analysis skills and understand how businesses can use sales data to make better decisions.

I worked with an e-commerce sales dataset and used Python to explore and clean the data. Then, I used Power BI to create an interactive dashboard where I could analyse sales, profit, product performance, and other business metrics.

## Tools I Used

* **Python** – for exploring and cleaning the data
* **Pandas and NumPy** – for working with the dataset
* **Matplotlib and Seaborn** – for data visualization, if used in the analysis
* **Power BI** – for building the dashboard
* **DAX** – for creating calculations and business metrics

## What I Did

* Explored the dataset to understand its structure and the information it contained.
* Checked for missing values and duplicate records.
* Cleaned and prepared the data using Python.
* Created measures in Power BI to calculate sales, profit, total orders, average order value, and profit margin.
* Built a three-page dashboard to explore different aspects of the business.

## Dashboard Overview

### 1. Sales Overview

This page gives an overall picture of sales and profit. It includes monthly sales trends, category performance, top-selling products, and sales across cities.

### 2. Product & Customer Analysis

This page focuses on product performance, sales by category, customer segments, discounts, and quantities sold.

### 3. Business Insights

This page helps explore monthly profit trends, profit by category, sales by city, order status, and payment methods.

## Key Metrics

The dashboard includes:

* Total Sales
* Total Profit
* Total Orders
* Total Quantity Sold
* Average Order Value
* Profit Margin

## What I Learned

While working on this project, I got practical experience with data cleaning in Python, creating DAX measures, working with data relationships, and building interactive dashboards in Power BI.

This project also helped me understand how to turn a raw dataset into visual reports that make business performance easier to explore.
